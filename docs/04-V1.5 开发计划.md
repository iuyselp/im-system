# IM 通信系统 - V1.5 开发计划

## 版本目标
在 V1.0 MVP 基础上，增加音视频通话、消息已读回执、聊天记录搜索等核心功能。

## 功能清单

### 1. 消息已读回执 ✅
- [x] 数据库字段扩展（message_read_status 表）
- [x] 标记已读接口
- [x] 获取未读消息数接口
- [x] 已读状态推送

### 2. 聊天记录搜索 ✅
- [x] 消息搜索接口（按关键词、时间范围、发送者）
- [x] 搜索结果高亮
- [x] 搜索历史记录

### 3. 音视频通话 ✅
- [x] 通话记录表（im_call_record）
- [x] 信令服务（呼叫、接听、挂断）
- [x] WebRTC 配置接口（STUN/TURN）
- [x] 通话历史查询

### 数据库变更
```sql
-- 消息已读状态表
CREATE TABLE `im_message_read` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `message_id` varchar(64) NOT NULL,
  `user_id` bigint NOT NULL,
  `read_at` datetime DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_msg_user` (`message_id`, `user_id`),
  KEY `idx_user` (`user_id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;

-- 通话记录表（扩展）
CREATE TABLE `im_call_record` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `call_id` varchar(64) NOT NULL,
  `caller_id` bigint NOT NULL,
  `receiver_id` bigint,
  `group_id` bigint,
  `type` varchar(20) NOT NULL COMMENT 'AUDIO/VIDEO',
  `duration` int DEFAULT 0 COMMENT '通话时长 (秒)',
  `status` varchar(20) DEFAULT NULL COMMENT 'ANSWERED/MISSED/REJECTED/CANCELLED',
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_caller` (`caller_id`),
  KEY `idx_receiver` (`receiver_id`),
  KEY `idx_created` (`created_at`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```
